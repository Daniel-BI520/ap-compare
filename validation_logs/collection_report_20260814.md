## 七、采集问题与数据说明

### 7.1 已知数据限制

1. **发布时间字段**：部分型号采用近似季度标注（如2024-Q1、2025-Q2），非精确日期
2. **彩页URL**：仅部分型号填充了datasheet_url，完整度约60%
3. **功耗数据**：部分型号功耗为典型值而非最大值，单位统一为W
4. **重量尺寸**：部分型号从产品彩页提取，可能与实际包装重量有差异

### 7.2 命名与单位规范

- **速率单位**：统一使用 Mbps（兆比特每秒）
- **功率单位**：统一使用 dBm（发射功率）、W（功耗）
- **温度单位**：统一使用 °C（摄氏度）
- **重量单位**：统一使用 kg（千克）
- **尺寸单位**：统一使用 mm（毫米），格式 宽×深×高

### 7.3 形态判定标准

| 形态 | 判定依据 |
|------|---------|
| 室内放装型 | 吸顶/壁挂安装、2-3射频、通用室内覆盖场景 |
| 室内高密型 | 3射频及以上、高空间流配置（≥8条流）、面向高并发场景 |
| 室外型 | IP67/IP68防护等级、宽温域、室外专用设计 |
| 面板型 | 86面板尺寸、墙装、带下行以太网口 |
| 智分/分布式 | 由主机+远端单元组成、馈线/网线分布覆盖 |

### 7.4 采集过程说明

1. **采集方法**：通过搜索引擎检索厂商官方产品页和技术规格文档，人工提取参数
2. **质量控制**：所有参数交叉验证至少2个官方来源（产品页+彩页/配置指南）
3. **排除范围**：家用/消费级AP（华为荣耀、H3C Magic、锐捷星耀等）全部排除
